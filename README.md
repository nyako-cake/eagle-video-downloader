# Eagle Video Downloader

[English](./README.en.md) | 中文

从 yt-dlp 支持的网站直接下载视频到 Eagle。基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 构建。

## 支持的平台

YouTube、Twitter / X、TikTok、Bilibili、Instagram、Pinterest、Dribbble、Vimeo、Sankaku、小红书 以及[更多平台](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)。

## 功能特性

支持 yt-dlp 支持的视频网站，首次运行需要在依赖管理页点击安装 yt-dlp，使用 Eagle 官方 FFmpeg 插件合并音视频，下载完成后自动导入到 Eagle 并保存元数据，支持中英文界面，显示实时下载进度。同时支持下载 Pinterest 纯图片 Pin（自动获取高清原图）。

## 新增与改动（3.2.0 – 3.10.0）

本分支相对上游 3.0.0 的主要改动如下。

### 站点与内容

- Sankaku（sankaku.app / sankakucomplex.com）：投稿视频与图片下载，可在设置页填入 accessToken 以获取仅登录可见内容
- 小红书（xiaohongshu.com）：笔记图片与视频下载，标题作为文件名、正文作为注释、话题作为标签；多图按标题编号，原图优先（HEIC 自动转 JPEG）；标签可在偏好设置「小红书标签」中关闭
- Twitter / X 图片：图片推文按原图尺寸保存，多图逐张下载，推文正文写入 Eagle 注释
- 一条推文包含多个视频时逐个下载，不再只取第一个

### 账号与自动抓取

- 设置页新增「账号」分页：Sankaku accessToken 与 Twitter / X 的 auth_token、ct0，均为密码输入框
- 填入 Twitter 凭证后可常驻显示头像、昵称与用户名
- 自动获取点赞与收藏：可分别勾选「抓取点赞」「抓取收藏」，按 2 分钟至 3 小时的时间选项定时抓取，新增内容自动加入下载队列
- 「抓取测试」按钮可立即执行一次抓取；插件启动时会自动补抓上次关闭后新增的内容
- 账号资料、抓取开关、时间选择与抓取记录按 Eagle 资源库隔离，切换资源库自动跟随
- 下载去重：同一条推文或 Sankaku 投稿在 24 小时内只下载一次，扩展推送与自动抓取不会重复入队

### 局域网发送

- 插件桥接改为监听 0.0.0.0:43110，并提供 GET /peers 扫描同网段内运行本插件的设备
- 浏览器扩展弹窗可扫描并记住设备，把当前页面链接发送到局域网设备；推文操作栏也有分享按钮，推文分享菜单里同样有「分享到局域网设备」
- 只发送链接，不在发送端下载；接收端需要打开插件并放行 43110 入站

### 下载能力

- 实时进度：下载中显示百分比、速度与剩余时间；合并 / 转码阶段显示估算进度，无法估算时显示不确定进度动画
- 多线程下载：偏好设置新增「下载线程数」（自动 / 8 / 16 / 32 / 64 / 128），映射到 yt-dlp `--concurrent-fragments`，对 HLS / DASH 分片流生效；直链 MP4 仍为单连接
- Twitter / X 受限内容：未登录时 X 对 NSFW / 年龄限制推文返回 TweetTombstone，插件改用公开接口解析直链后交给 yt-dlp 下载，普通推文仍走原有逻辑

### 界面与交互

- 界面：贴近 Eagle 的浅色面板风格；偏好设置「外观」可选 6 套主题，或开启「跟随 Eagle 主题」自动同步 Eagle 外观
- 输入框剪贴板按钮：读取系统剪贴板，自动从「文字 + 链接」的混合内容中提取 https 链接，填入后自动点亮下载按钮
- 窗口置顶：右上角图钉按钮，调用 `eagle.window.setAlwaysOnTop`，状态写入 localStorage 并在下次打开时恢复
- 窗口可缩放：最小 360 × 420，缩放停止 300ms 后保存，关闭窗口时立即保存，下次打开恢复上次尺寸
- 删除记录：每个下载项右上角悬停出现 ×，正在下载或解析中的任务不可删除，删除不影响已导入 Eagle 的素材

### 导入信息规则

- 设置页顶部切换栏新增「导入信息规则」页签，位于「偏好设置」之后，集中管理导入 Eagle 时自动写入的标签与素材命名规则
- 原偏好设置里的「小红书标签」开关迁入该页，开关状态沿用已保存的值，不需要重新设置
- 该页说明标签写入规则：小红书笔记写入话题标签，其他站点写入站点标识，单次导入最多 30 个标签
- 推特信息规则：同一页的「推特信息规则」卡片用复选框决定导入素材名称，可选推特 ID（作者数字 ID）、推文 ID、用户名（@handle）、推文正文、推特全名
- 每个字段右侧有上移 / 下移按钮，拼名顺序按你调整后的顺序，用「 - 」连接；默认全部不勾时沿用「推文正文 - @用户名」，超 150 字截断，文件名非法字符会被替换
- 同一条推文有多张图片或多个视频时，导入名末尾自动追加「 (1/N)」，几个文件不会互相重名
- 推特注释规则：同一页的「推特注释规则」卡片同样用五个复选框和上下箭头决定导入素材的注释，勾选状态与顺序独立保存
- 注释默认一项都不勾，此时沿用推文正文；勾选后按调整后的顺序用「 - 」连接，不再自动带正文，想保留正文需勾选「推文正文」；注释不清理文件名非法字符，总长上限 5000 字符

### 桥接与局域网

- 插件在 `0.0.0.0:43110` 提供 `GET /ping`、`GET /peers` 与 `POST /ingest`，本机扩展与局域网设备都可访问
- `/peers` 会扫描本机所在网段，返回正在运行本插件的设备列表
- 仅接受 https 且域名在 x.com / twitter.com / video.twimg.com / pbs.twimg.com / sankaku / xiaohongshu 白名单内的链接，请求体上限 16 KB
- 依赖未就绪时返回 503；收到链接后自动入队，并唤起插件窗口

## 浏览器扩展（Edge / Chromium）

配套扩展位于 `edge-extension/`（Manifest V3）。

安装步骤：打开 `edge://extensions`，开启「开发人员模式」，点击「加载解压缩的扩展」，选择 `edge-extension/` 目录。

功能：

- X / Twitter：推文操作栏注入「保存到 Eagle」下载按钮和「分享到局域网设备」分享按钮，推文分享菜单里也有「分享到局域网设备」
- 点赞或收藏帖子时自动推送链接，可在扩展弹窗分别开关
- Sankaku：页面右下角浮动按钮，推送当前帖子链接
- 小红书：笔记页右下角浮动按钮，保存当前笔记（标题作为文件名，正文与话题写入 Eagle）；链接需带 xsec_token
- 弹窗「局域网设备」：扫描并记住同网段设备，发送当前页面链接（只发送，不在本机下载）
- 插件未打开时，扩展会通过 Eagle 本地接口尝试唤醒插件，再重试推送
- 插件不可用时，对直链媒体退回 Eagle 本地 API `127.0.0.1:41595`

## 安装方式

手动安装：下载[最新版本](https://github.com/nyako-cake/eagle-video-downloader/releases)，在 Eagle 中选择 插件 → 开发者选项 → 导入本地项目。

## 首次运行

首次启动时需要在依赖管理页安装 yt-dlp（约 30MB）。ffmpeg 使用 Eagle 官方 FFmpeg 插件；若本地未安装，可在依赖页点击按钮一键跳转至 Eagle 应用商店下载。

## 使用方法

1. 复制页面链接
2. 粘贴到插件输入框（点击输入框左侧的粘贴按钮会自动识别并开始下载）
3. 或直接在 X / Twitter 推文上点操作栏的保存按钮、点赞、收藏，由扩展推送；在小红书笔记页点右下角浮动按钮保存当前笔记
4. 下载完成后自动导入到 Eagle

## 常见问题

- 提示「yt-dlp 未安装」：到「依赖管理」页重新安装；若网络无法访问 GitHub，可手动下载 yt-dlp 可执行文件放到插件目录下的 `bin/` 中（Windows 为 `yt-dlp.exe`），重启插件即可
- 下载没有速度或进度不动：优先检查系统代理是否可用，yt-dlp 会沿用系统代理设置
- 浏览器扩展提示「请先打开 Eagle 插件」：插件窗口未打开或依赖未就绪，打开插件窗口后重试
- 受限推文（NSFW / 年龄限制）下载失败：确认插件窗口处于打开状态，插件会通过公开接口解析直链
- 合并阶段百分比跳变：合并进度按输出文件增长估算，小文件可能从 0% 直接跳到 100%
- 局域网扫描不到设备：确认两台设备在同一网段、接收端已打开 Eagle 插件，并在 Windows 防火墙放行 43110 入站
- 重复下载：插件按推文 / 投稿 / 笔记去重，24 小时内同一内容只会下载一次；如仍重复，检查是否同时开启了扩展推送与自动抓取同一来源
- 小红书提示「无法读取该笔记」：链接需要带 xsec_token，请从 App 分享菜单或浏览器地址栏复制完整链接（形如 `.../explore/<id>?xsec_token=...`），只有笔记 ID 的链接无法匿名读取

## 开发

```bash
npm install      # 安装依赖
npm run build    # 构建插件
npm run dev      # 开发模式（监听文件变化）
npm run package  # 打包插件
```

项目使用 esbuild 打包，i18next 国际化，yt-dlp 负责视频提取，ffmpeg 由 Eagle 官方 FFmpeg 插件提供。

## 系统要求

Eagle 4.0 或更高版本，需安装 Eagle 官方 FFmpeg 插件，需要网络连接。
